# My_Little_Fan
An Arduino-based fan control system using a humidity sensor and Bluetooth.

## Project Overview
This Fan system can be controlled in two-ways
- Automatic Mode: Fan operates based on humidity level.
- Manual Mode: Fan can be controlled remotely via Bluetooth using a smartphone application built with MIT App Inventor.

## 🔧 Hardware Coomponents
- Arduino Uno
- 12VDC Fan
- 12VDC adapter
- humidity sensor (dht11)
- Bluetooth module (HC-06)
- 5V relay module

## System Features
- Real-time humidity monitoring
- Automatic fan control based on humidity threshold
- Manual ON/OFF control via Bluetooth
- Mode switching (Auto / Manual)
